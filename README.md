## 🇨🇳 中文

面向需要制作 3D 漫剧半解说短剧的创作者，可从故事、剧本片段、参考图或已有素材开始。流程先确认剧情与交付选项，完成剧本对账，在分镜阶段预留旁白和对白时间窗，建立角色与场景锚点，生成定时音频和图生视频镜头，再按确认顺序拼接无旁白的对白视频。旁白作为独立音频包交付，方便用户自行剪辑。每个不可逆决策点都用选项卡提问并给出合理默认值，用户确认或挑选即可，不需要从零写简报。适合短篇连续 3D 漫剧，不负责真人实拍、纯二维动画、旁白混音母版或长篇系列统筹。

### ✨ 能做什么

- 交互式起手一次问 5 题：起始路径、题材轨道、格式锁定、视觉风格确认、旁白音色，每题带默认值
- 硬关卡「剧情不删减」：原剧本每个剧情点都保留，不许压缩或改写来适应时长
- 硬关卡「画布门禁」：最终规格、核心资产与视频生成前产物都必须在画布上
- 硬关卡「用户语言跟随」：所有面向用户的输出跟随用户当前语言，用户原文逐字保留
- 资产轻量化：每主要角色 1 张主卡 + 1 张三视图，每主要场景 1 张主卡 + 1 张辅卡，至多 1 张道具卡
- 交付 QC 逐镜记录证据时间段与通过/警告/失败/未核验，返工只动有证据的镜头，不整集回滚

## 🇬🇧 English

For creators developing a 3D manhua half-narrated short drama, starting from a one-line story, a rough script fragment, a reference image, or existing assets. The workflow confirms story and delivery options, reconciles the script, reserves narration and dialogue windows at storyboard stage, builds character and scene anchors, generates timed audio and image-to-video shots, then assembles a dialogue-only video in the approved order. Narration ships as a separate audio package for user-led editing. Every irreversible decision point is asked as a tabbed question with a sensible default, so users confirm or pick instead of writing a brief from scratch. Best for short episodic 3D manhua; it does not cover live action, pure 2D animation, narration master mixing, or long-form series planning.

### ✨ What it does

- Interactive start asks 5 questions at once — start point, genre track, format lock, visual style confirm, narrator voice — each with a starred default
- Hard gate "no plot cut": every plot point of the original script survives, never compressed or rewritten to fit the runtime
- Hard gate "canvas gate": final specs, core assets, and pre-generation deliverables must all sit on the canvas
- Hard gate "user language follow": every user-facing output follows the user's current language, with original text kept verbatim
- Lightweight assets: 1 main card + 1 three-view per main character, 1 main + 1 supporting card per main scene, at most 1 prop card
- Delivery QC logs each shot's evidence window as pass/warning/fail/unverified; rework touches only evidenced shots instead of rolling back the episode
